# Proof & Authority Map

## The seven-level hierarchy

| Level | Meaning | Language allowed on site |
|---|---|---|
| **L1** | Direct client credit on published work | "credited by", "caption credit" |
| **L2** | Instagram collaboration with Francesco | "published in collaboration with" — **never** "credited" |
| **L3** | Client-published work clearly corresponding to his | "published by" |
| **L4** | Google review | "5-star Google review" |
| **L5** | Editorial publication / festival credit | name the publication or festival |
| **L6** | External backlink / press mention | name the source |
| **L7** | Self-authored case-study statement | plain narration, no proof claim |

**The distinction that must never blur:** L2 ≠ L1. A collaboration post proves
the client made the work *with* him; it does not prove they wrote his name.

## Rules

- Never manufacture authority.
- Never call an unlinked mention a backlink.
- Never call an Instagram mention a press feature.
- Never add Review/AggregateRating schema to harvest stars.
- An Instagram Collab post **is** valid proof — do not undercount it just
  because the caption has no "@" credit.
